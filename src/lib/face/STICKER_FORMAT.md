# Open_Edit sticker format

A sticker is a JSON object consumed by `src/lib/face/sticker.ts` (`StickerDef` / `StickerItemDef`) through
`parseSticker(json, basePath)`. Resource names resolve against `basePath`; the built-in stickers live in the asset
pack (`public/packs/open/stickers/`, kind `sticker`, definition in `meta.def`) and are generated by
`scripts/gen-stickers.mjs`.

```jsonc
{
  "stickerId": 104,
  "name": "Shades",
  "items": [
    {
      "id": "glasses",
      "drawType": "FACE_3D",                // FACE | FACE_3D | FACE_MASK | FACE_SKIN | COLOR_LENS | BACKGROUND | SEGMENTATION | FACE_DISTORTION | BUILT_IN | OCCLUDER
      "triggerType": "FACE_DETECT",         // see Triggers
      "faceLocationType": "EYES_CENTER",    // see Anchors
      "anchorType": "CENTER",               // CENTER | LEFT | RIGHT | TOP | BOTTOM | LEFT_TOP | LEFT_BOTTOM | RIGHT_TOP | RIGHT_BOTTOM
      "translateX": 0, "translateY": 0.03, "translateZ": 0.15,   // eye-distance units, face frame
      "scale": 2.5,                         // item width in eye-distance units
      "rotateZ": 0,                         // degrees, extra in-plane rotation
      "rotationMode": "VARIANT",            // VARIANT: follow head roll | INVARIANT: stay upright
      "alpha": 1,
      "blendType": "NORMAL",                // any blend mode name: NORMAL, MULTIPLY, SCREEN, OVERLAY, SOFTLIGHT, HARDLIGHT, ADD, COLOR, ...
      "flipHorizontally": false,
      "faceIdx": -1,                        // -1 = every tracked face, n = only the n-th face
      "resourceType": "IMAGE",              // IMAGE | SEQUENCE | SPRITE
      "resourceName": "shades/glasses.svg", // IMAGE / SPRITE file
      "frames": ["sparkles/f_00.svg"],      // SEQUENCE: explicit list, or a printf-style pattern:
      "framePattern": "pop/f_%02d.svg", "frameStart": 0, "frameCount": 12,
      "columnCount": 4, "rowCount": 6,      // SPRITE sheet grid (frameCount defaults to columns*rows)
      "fps": 24,
      "repeatCount": 0,                     // loops per trigger; 0 = forever (default for continuous triggers, 1 for *_BEGIN)
      "segmentation": { "target": "background", "color": "#ff00aa" },  // BACKGROUND / SEGMENTATION only
      "color": "#4a9ae0", "pattern": "starburst",                     // COLOR_LENS without a resource: procedural iris tint
      "warp": [                             // local deformations while the item is on (WarpOp, warp.ts)
        { "type": "scale", "anchor": 468, "rx": 0.3, "amount": [0.2, 0.2] }
      ],
      "warpWeight": 1
    }
  ],
  "shape": { "eyeSize": 0.4, "faceSlim": 0.2 },   // reshape values added to the user's (WarpParams)
  "shapeSides": { "faceSlim_left": 0.3 },         // per-side reshape (ShapeWeights)
  "makeup": { "layers": [ /* MakeupLayer[] (makeup.ts) */ ], "teethWhiten": 0.3 }  // makeup preset
}
```

## Coordinate frame

- Units: the face's **eye distance** (3D distance between outer eye corners, landmarks 33 and 263), so items keep
  their size when the face turns.
- `x` points to the screen right along the eye line (never mirrored, so text in a sticker stays readable on the
  mirrored front camera), `y` points toward the chin, `z` toward the camera.
- `FACE` items rotate with roll only (flat 2D). `FACE_3D` items use the full head rotation (yaw / pitch / roll, from
  the landmarks' 3D basis) with an orthographic projection, so a pair of glasses foreshortens when the head turns.

## Anchors (`faceLocationType`)

LEFT / RIGHT are the **screen** sides of the displayed image. Landmark numbers are MediaPipe face mesh indices.

| value | landmarks |
| --- | --- |
| `FACE` / `EYES_CENTER` | 168 |
| `FACE_CENTER` | 197 |
| `EYE_LEFT` / `EYE_RIGHT` | eye centers |
| `EYEBROW_L` / `EYEBROW_R` | 105 / 334 |
| `NOSE` / `NOSE_B` / `NOSE_L` / `NOSE_R` | 1 / 2 / nostril 98 or 327 |
| `MOUTH` / `MOUTH_T` / `MOUTH_B` | average of 78, 308, 61, 291 / 0 / 17 |
| `CHIN` | 152 |
| `EAR_LEFT` / `EAR_RIGHT` | face edge 234 / 454 pushed 12% further from the nose |
| `FOREHEAD_LEFT` / `FOREHEAD_CENTER` / `FOREHEAD_RIGHT` | 54 / 10 / 284, raised 15% of the glabella-to-10 distance |
| `HEAD_TOP` | 10 raised 50% of the glabella-to-10 distance (hats, crowns) |

## Triggers (`triggerType`)

Expressions come from MediaPipe blendshapes (`expressions()` in tracker.ts): mouth open = `jawOpen > 0.35`, blink =
both `eyeBlink* > 0.5`, brow raise = `browInnerUp > 0.5` (or outer brows), kiss = `mouthPucker > 0.6`, smile = mean
`mouthSmile* > 0.5`, nod = pitch changes by more than 0.12 rad from its running average.

| trigger | behaviour |
| --- | --- |
| `ALWAYS` | always visible (screen items default to this) |
| `FACE_DETECT` | visible while the face is tracked (face items default to this) |
| `ALL_FACE_GONE` / `TWO_MORE_FACE_DETECT` | no face / two or more faces |
| `MOUTH_OPEN`, `MOUTH_CLOSE`, `EYE_BLINK`, `KISS`, `BROW_JUMP`, `SMILE` | visible while the condition holds; the animation restarts on each rising edge |
| `*_BEGIN`, `EXCLUSIVE_*` (`MOUTH_OPEN_BEGIN`, `PITCH_BEGIN`, `BROW_JUMP_BEGIN`, `EXCLUSIVE_EYE_BLINK`, ...) | a rising edge starts the animation, which plays `repeatCount` (default 1) loops and then hides |
| `DISAPPEAR_*` | visible until the condition first happens |
| `TOUCH_TAP`, `TOUCH_TAP_BEGIN` | call `runtime.tap()` on a screen tap |

## Draw types

- `FACE` / `FACE_3D`: a textured quad anchored as above. NORMAL uses alpha compositing; other blend modes blend
  against the frame under the sticker.
- `FACE_MASK` / `FACE_SKIN`: the image is a whole-face texture in **MediaPipe canonical face UV space** (the layout
  of `canonical_face_model_uv_visualization.png`, v pointing down) draped on the 468-point face mesh; back-facing
  triangles are culled. `flipHorizontally` mirrors u. Drawn under the sprites. The built-in glitter, freckles and
  mesh-scan stickers are drawn this way.
- `COLOR_LENS`: an iris disc on landmarks 468 / 473, sized to the iris and clipped by the eye opening. Either an image
  (`resourceName`) or a procedural tint (`color`, `pattern`: ring | starburst | solid).
- `BACKGROUND` / `SEGMENTATION`: the image (cover-fit to the view) or `segmentation.color` replaces the region chosen
  by `segmentation.target`: `background` (default, 1 - person), `person`, `hair` (a colour keeps the hair luminance,
  for hair dye), `skin`. Needs `FaceRenderParams.segmentation` (from `FaceTracker.segment`).
- `FACE_DISTORTION` / `BUILT_IN`: no image; used to carry `warp` deformations, or simply to activate the
  sticker-level `shape` / `makeup` presets.
- `OCCLUDER`: not drawn. Renders a procedural head volume (an ellipsoid fitted to the eye distance and head pose,
  inset 0.15 IOD behind the face) to depth, so `FACE_3D` items placed behind the head (`translateZ` < 0: ears, hats,
  halos) are hidden by it as the head turns. Items on the face surface are never hidden.

## Sticker-level presets

- `shape` (WarpParams) and `shapeSides` (ShapeWeights) are added to the user's reshape while the sticker is on.
- `makeup` is a MakeupParams preset added after the user's makeup (procedural layers: lips, blush, eyeshadow, liner,
  `lash3d` strips, iris tints and catchlights, gloss / glitter).

## Not supported

Particle systems, 3D model props, scripted stickers, sound and text captions.
